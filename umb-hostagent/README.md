# umb-hostagent

`umb-hostagent` is the Java agent and 26.2-side runtime. It starts the legacy
loaders, registers native twins for legacy content, and forwards world,
player, inventory, entity, GUI, sound, and rendering operations between the
two Minecraft versions.

The legacy modules run in isolated classloaders. The host agent owns the real
26.2 world and registry; legacy code sees facades that translate calls into
that world. Offline maps and snapshots generated by `umb-guimap`,
`umb-rendermap`, and the snapshot fixture provide registration and rendering
metadata.

## Build and test

```powershell
tools\windows\build-hostagent.ps1
tools\windows\run-hostagent-tests.ps1
```

The build creates `build\hostagent\umb-hostagent.jar`. Pass it as a Java agent
when launching Minecraft, together with the arguments described in
`docs/INSTALL.md`.

## Key classes

- `HostAgent` — Java-agent entry point and transformer registration.
- `UmbBridgeHost` — lifecycle and bridge access.
- `Registrar` — native block, item, entity, menu, and block-entity registration.
- `HostWorldImpl` and `HostPlayerImpl` — 26.2 implementations of legacy facades.
- `UmbLegacyBlock` and `UmbLegacyBlockEntity` — native twins for legacy blocks and tiles.
- `PackGen` — resource-pack generation for names, models, and textures.
- `Hooks` and the patcher classes — small bytecode seams into 26.2 lifecycle code.
